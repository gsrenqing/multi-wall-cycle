# MultiWallCycle（多屏幻灯壁纸）v2.4 使用说明

> 程序全名：**MultiWallCycle**，中文显示名「多屏幻灯壁纸」·版本 2.4.0.0·绿色免安装
> 用途：多屏显示环境下，每块屏用各自的一组壁纸，按设定间隔自动更换。

## 一、快速开始

1. 把 `MultiWallCycle.exe` 放到一个**固定的、不会被误删的文件夹**（例如 `D:\Tools\MultiWallCycle\`）。
   - 想"配置随身走"（绿色便携）：同目录再放一个 `config.json`，程序就只读这个文件，不写系统用户目录。
2. 双击运行，窗口打开。
3. 每块屏各做两件事：**选壁纸文件夹**、**设更换间隔**。
4. 点右下角 **「保存并应用」**。保存后窗口不会关闭，也不会退到托盘。
5. 启动后**不会立刻换壁纸**，只开始计时；到达间隔才换第一张（想马上换就点「立即全部更换」）。

## 二、界面与交互规则（草稿制，与旧版一致）

| 操作 | 效果 |
| --- | --- |
| 改动任何设置 | 只改"界面草稿"，不影响正在跑的壁纸 |
| 点「保存并应用」 | 草稿生效 + 写盘，窗口保持打开 |
| 点「立即更换」/「立即全部更换」 | 用当前草稿立刻换图预览（不写盘） |
| 点窗口右上角 × | 丢弃未保存的草稿、恢复上次生效配置，程序退到托盘继续跑 |
| 托盘右键「退出」 | 真正结束程序 |

## 三、界面语言（v2.3 新增）

### 3.1 首次启动会自动选

- 系统界面语言是中文（zh-CN / zh-TW / zh-HK…）→ **中文界面**
- 其余语言 → **英文界面**

判定结果会写进 `config.json` 的 `Lang`，之后**只认你的选择**，不再跟着系统语言变。

### 3.2 想换成另一种语言，两个入口都行

1. **主界面按钮**：中文界面左下偏右位置显示 **English**，点它切英文；英文界面同位置显示 **中文**，点它切中文。
2. **托盘右键菜单**：菜单里同样有一项 `English` / `中文`。

切换是**整窗即时生效**，不用重启；切换前界面上未保存的改动会被保留（但要真正生效仍需点「保存并应用」）。

英文界面下窗口尺寸不变，程序会自动把较长的英文标签拉开（顶栏复选框加宽、状态文字右移、卡片按钮微调），中文界面的像素位置与 v2.2 **完全一致**。

### 3.3 两套界面里固定的中文元素

- 中文界面的窗口标题仍是「**多屏幻灯壁纸 - 设置**」；英文界面标题是「MultiWallCycle - Settings」。
- 「关于」弹窗**只显示当前界面的一种文字**：中文界面是中文正文，英文界面是英文正文（不再中英同窗）。窗口**按内容自动量尺寸**（实测 429×274），并限制在屏幕工作区的 90% 以内，1080×1920 竖屏也能完整显示。英文版落款为 `Autumn 2026 · Garzê Tibetan Autonomous Prefecture, Sichuan, China · Version 2.4`。

### 4.1 顺序轮换的规则

按**文件修改时间**排序，从最旧与最新两端交叉取图：第 1 张最旧 → 第 2 张最新 → 第 3 张第 2 旧 → 第 4 张第 2 新 …… 一直到中间。每次换图后立即保存进度（`SeqPos`），正常退出、关机、注销时再存一次，所以**重启后接着上次的位置轮换，不会回到第 1 张**。

### 4.2 必应每日壁纸的取图方式

- 数据来自必应官方接口（`HPImageArchive`，取最近 8 条），自动下载 UHD 原图到配置目录下的缓存。
- 勾了必应**不再强制 24 小时间隔**（v2.2 起）：按你设的间隔，在最近 8 张里按「时间倒序」或「随机」更换。
- 同时勾了本地文件夹和必应时，**本地优先**，本地取不到才用必应。
- **同时勾了必应和本地文件夹时，当天那张必应 4K 原图会自动存进这个文件夹**（v1.1.2 起就有，v2.4 补上了标题）。文件名用必应官方原名（如 `AbrahamCanada_ZH-CN0344365912_UHD.jpg`），并且**标题会按《动态壁纸》的规则直接写进图片 EXIF**——所以这张图之后即使用别的软件打开、甚至 meta 缓存被清掉，标题都还在。
- 本地文件夹里的必应图累积超过 90 天时，托盘会提醒一次（每 90 天最多一次），建议手动清理。

### 4.3 文字描述的大小与可读性

- 字号是**像素级锁定**的（v2.2 修复）：同一块屏，无论壁纸是 1920×1080 还是 4K，文字看起来都一样大，不随图片分辨率缩放。
- **关掉阴影也能看清**（v2.3）：程序会看文字所在那一块的明暗，自动补一道极细的对比影——亮底（雪景、白天空）自动黑边，暗底自动白边。你看到的仍是"无阴影"的干净文字。
- **v2.4 起，文字描述不再只属于必应图**。任何来源的图片都按同一条链路取标题：必应下载记录 → 图片内嵌 EXIF（`ImageDescription` / `XPTitle`）→ 图片内嵌 XMP（`dc:title`）。有标题就显示，**没有标题就什么都不画**（不报错、不弹提示）。自己拍的照片、从别的软件存的图，只要文件里带标题（Windows 资源管理器"详细信息"里的"标题"字段就是它），现在都能显示。
- 判断依据是**图片自身的内容**，不再看文件名。以前"文件名不像必应图就一律不给文字"的白名单已经去掉。
- 文字描述设置窗**按内容自动定高**，放不下时内容区可滚动，底部「确定 / 取消」永远可见——DPI 缩放到 125%/150%/175%/200% 都不会再出现"字被吃半行"。
- 本地图没有标题时点「确定」，程序会正常返回、不改动壁纸；要给它加标题，可用 Windows 资源管理器右键图片 →「属性」→「详细信息」→「标题」填一个，或任何支持写 EXIF 的工具。

## 五、「卸载」按钮（v2.3 位置变了，请注意）

位置：**窗口最下一行最左端**，尺寸比标准按钮小 30%（77×22），就是为了不容易被误点。它原来的位置（居中偏右）现在是语言切换按钮。

点它会弹确认框（**内容随界面语言切换**，中文沿用 v2.2 原文，英文为新译）。

### 确定后会发生什么

1. 删除注册表自启项：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `MultiWallCycle` 与旧的 `多屏幻灯壁纸`，并扫描其它数据含这两个名字的值一并删除；
2. 删除程序生成的所有文件：`config.json`、`bing_meta.json`（必应描述缓存）、`log.txt`（仅测试版有）、`temp` 缓存，覆盖 exe 同目录、`%LOCALAPPDATA%\MultiWallCycle` 与旧版目录 `%LOCALAPPDATA%\多屏幻灯壁纸`；
3. 停止轮换、释放托盘，退出进程；
4. 由程序调用系统接口把 **exe 自身移入回收站**（可还原）。

### 不会删什么

- **你的壁纸图片**（本地文件夹里的原图、必应图库里的收藏）一律不动。
- 系统回收站之外的任何文件不动。

### 想彻底清除

清空回收站即可。若中途提示"部分项目未能清理"（常见原因是另一个登录会话里还有实例在跑），按提示手动删残留目录即可。

## 六、托盘操作

托盘图标右键菜单（顺序固定）：

1. 打开设置（等同双击托盘图标）
2. 立即全部更换
3. 暂停全部 / 继续全部
4. ——分隔线——
5. English / 中文（语言切换）
6. 关于（按当前界面语言显示对应文字）
7. 退出（彻底结束程序）

**最小化 / 关窗不再弹气泡**（v2.3 起）。点右上角「×」仍是"丢弃未保存草稿、退到托盘"，只是不再弹"未保存的修改已放弃"的提示；程序是否还在跑，看托盘图标即可。功能类提示（无显示器可绑定、必应缓存超 90 天、显示器布局变化、重扫结果）仍会弹，那些是"不提示就会误判"的信息。

**「暂停全部」是会话级开关**（v2.3 第三批）：暂停后本次运行内不再自动换图，重启程序即恢复轮换——因为"程序在跑就轮换"已经是恒定默认，没有持久化的"关掉轮换"这种状态了。想长期不换图，直接退出程序（或从托盘「退出」）即可。

**托盘与资源管理器用的是同一个图标**（v2.3 第三批）：`app.ico` 已编进 exe（16/24/32/48/64/128/256 七个尺寸按尺寸重绘，不是拉伸），列表小图标到"超大图标"都清晰。替换新 exe 后如果资源管理器还显示旧的白纸图标，那是 Windows 的图标缓存，按 `Win+R` 输入 `ie4uinit.exe -show` 或重启资源管理器即可刷新。

## 七、配置与日志

### 7.1 配置文件位置

- **便携模式**：exe 同目录下有 `config.json` → 就用它（整个文件夹拷走，配置跟着走）。
- **普通模式**：`%LOCALAPPDATA%\MultiWallCycle\config.json`。

从 v2.2 升级：首次以普通模式运行时会**自动把旧目录** `%LOCALAPPDATA%\多屏幻灯壁纸` 里的 `config.json`、`bing_meta.json` **复制**到新目录；旧目录不删不改，卸载时一并清理。所以你的屏配置、间隔、文字样式都会带过来。

### 7.2 日志

**正式版没有日志文件**（编译期已移除所有写日志调用）。需要排查问题时用测试版 `MultiWallCycle_Test.exe`，它会在配置目录写 `log.txt`（超过 1MB 自动清空）。

### 7.3 临时文件

必应图片与裁剪缓存放在配置目录下的 `temp\`，条数固定（不会无限膨胀），随用随覆盖。

### 7.4 显示器绑定

配置按**显示器设备路径**（`\\?\DISPLAY#...`）保存，拔插、换口、重启后仍能对应到原来的那块屏；只有路径缺失的旧配置才回落到"按下标"绑定。界面上的"型号"取自显示器 EDID（如 `ViewSonic VX2762-2K-HD`）。

## 九、已知边界

1. 必应图片的**文字描述内容**来自必应中文站，切英文界面不会把它翻成英文。
2. 「必应每日壁纸」那个小方框在自动化工具/读屏里名字不理想（会借用相邻标签），不影响鼠标使用。
3. 单实例限制是"整台机器"级的：同一台机器开两个实例会被拦下（第二个会把已运行窗口提到前台）。
4. 必应页递归归档站（`bing.wdbyte.com`）是第三方站点，若某天它的日页规则变化，链接会自动退回该站首页——程序不会因此报错。
5. **「跟随主显示器」的屏只有在显示器 1 启用并在换图时才跟着换**。若把显示器 1 取消勾选（停用），跟随屏就没有可跟的对象，会停在那张图上不动——这是该选项的语义，不是故障。想让跟随屏自己换，取消它的「跟随主显示器」即可。
6. **11 月 2 日～13 日入库的那几张必应图没有内嵌标题**（v2.4 之前的版本只记在 `bing_meta.json`，没写进图片）。按你的决定不做批量回填，需要时手动补即可；v2.4 起新入库的图都自带标题。
